# Планировщик задач

**cron** — периодические задания; **at** — разовый запуск ко времени.

## ⏰ Планировщик задач (cron)

??? tip "⏰ cron (планировщик задач)"
    ### ⏰ cron

    cron — системный демон Linux для автоматического выполнения задач по расписанию.

    📌 Как работает:

    - постоянно работает в фоне
    - проверяет расписание каждую минуту
    - запускает задачи из crontab

    📌 Где используется:
    - бэкапы
    - очистка системы
    - отправка логов
    - периодические скрипты


??? tip "📄 crontab (управление задачами)"
    ### 📄 crontab

    crontab — инструмент для управления задачами cron.

    📌 Основные команды:

    ```bash
    crontab -e        # редактировать задания
    crontab -l        # показать задания
    crontab -r        # удалить все задания
    crontab -i        # удаление с подтверждением
    ```

    📌 Для конкретного пользователя:

    ```bash
    crontab -u user_name -e
    ```

    📌 Проверка:

    ```bash
    crontab -l
    ```


??? tip "🧠 Синтаксис cron (расписание задач)"
    ### 🧠 Синтаксис cron

    Формат строки:

    ```text
    * * * * * command
    ```

    📌 Расшифровка:

    ```text
    ┬ ┬ ┬ ┬ ┬
    │ │ │ │ │
    │ │ │ │ └─ день недели (0–7)
    │ │ │ └─── месяц (1–12)
    │ │ └───── день месяца (1–31)
    │ └─────── час (0–23)
    └───────── минута (0–59)
    ```

    📌 Пример:

    ```bash
    0 2 * * * /script/backup.sh
    ```

    → каждый день в 02:00


??? tip "📌 Примеры расписаний cron"
    ### 📌 Примеры расписаний

    ```bash
    * * * * * command
    ```

    📌 Частые кейсы:

    ```bash
    */5 * * * * command        # каждые 5 минут
    0 * * * * command          # каждый час
    0 0 * * * command          # каждый день в полночь
    0 2 * * 1 command          # каждый понедельник в 2:00
    0 0 1 * * command          # первое число месяца
    ```

    📌 Спецсимволы:

    - `*` → любое значение
    - `*/n` → каждые n единиц
    - `,` → список значений
    - `-` → диапазон


??? tip "⚙️ Работа ОС с cron"
    ### ⚙️ Работа ОС с cron

    cron взаимодействует с системой через:

    - /var/spool/cron/ → пользовательские задания
    - /etc/crontab → системный crontab
    - /etc/cron.d/ → дополнительные задания
    - /etc/cron.* → периодические папки

    📌 Важное отличие:

    ```text
    user crontab → без указания пользователя
    system crontab → требует user field
    ```

    📌 Формат /etc/crontab:

    ```text
    m h dom mon dow user command
    ```


??? tip "🧾 Логи cron"
    ### 🧾 Логи cron

    cron пишет события в системные логи.

    📌 Где смотреть:

    ```bash
    /var/log/syslog        # Ubuntu/Debian
    /var/log/cron          # CentOS/RHEL
    ```

    📌 Фильтрация:

    ```bash
    grep CRON /var/log/syslog
    ```

    📌 systemd journald:

    ```bash
    journalctl -u cron
    journalctl -u crond
    ```

    📌 Типичные проблемы:

    - неправильный PATH
    - отсутствие прав
    - неуказанная среда (cron не bash shell)


??? tip "🔄 Переменные окружения в cron"
    ### 🔄 Переменные окружения

    cron не использует полноценное окружение пользователя.

    📌 Часто нужно явно задавать:

    ```bash
    PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
    ```

    📌 Пример:

    ```bash
    * * * * * PATH=/usr/bin:/bin /home/user/script.sh
    ```


??? tip "🧪 Отладка cron"
    ### 🧪 Отладка cron

    Если задача не работает:

    📌 Проверить лог:

    ```bash
    grep CRON /var/log/syslog
    ```

    📌 Проверить выполнение вручную:

    ```bash
    bash script.sh
    ```

    📌 Добавить вывод в лог:

    ```bash
    * * * * * /script.sh >> /tmp/log.txt 2>&1
    ```


??? tip "🧭 Альтернативы cron"
    ### 🧭 Альтернативы cron

    Помимо cron существуют другие планировщики:

    📌 systemd timers (современный стандарт):

    ```bash
    systemctl list-timers
    ```

    📌 at (одноразовые задачи):

    ```bash
    at now + 5 minutes
    ```

    📌 batch:

    - выполняет задачи при низкой нагрузке системы

    📌 airflow / kubernetes cronjobs:

    - для распределённых систем
    - для DevOps / production pipelines

    📌 сравнение:

    - cron → простой и классический
    - systemd timers → современный и точный
    - kubernetes cronjob → cloud-native
