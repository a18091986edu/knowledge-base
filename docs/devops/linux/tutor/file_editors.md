# Файловые редакторы в терминале

**nano** — быстрый старт; **vim** — мощный редактор с режимами. Для разовых правок конфигов на сервере часто хватает `nano`.

---
??? tip "✏️ nano"
    ### ✏️ nano
    ```bash
    
    Ctrl + O    # сохранить
    Ctrl + X    # выйти

    Ctrl + K    # вырезать строку
    Ctrl + U    # вставить

    Ctrl + W    # поиск
    Ctrl + \    # замена

    Alt + U     # отмена
    ```
---
??? tip "⚡ vim"
    ## ⚡ vim

    ### 📚 Обучение
    ```bash
    vimtutor           # встроенное обучение
    ```

    ### 🧭 Normal mode (по умолчанию)
    ```bash
    Esc                # переход в normal mode

    dd                 # удалить строку
    5dd                # удалить 5 строк

    u                  # отмена
    p                  # вставка

    /text              # поиск
    n                  # следующий результат
    ```

    ### ✏️ Insert mode (режим ввода)
    ```bash
    i                  # начать ввод текста
    ```

    ### 🔲 Visual mode (выделение текста)
    ```bash
    v                  # начать выделение
    V                  # выделить строками
    Ctrl + v           # блочное выделение

    y                  # копировать (yank)
    d                  # удалить выделенное
    p                  # вставить
    ```

    ### ⚙️ Command mode (через :)
    ```bash
    :w                 # сохранить
    :q                 # выйти
    :wq                # сохранить и выйти
    :q!                # выйти без сохранения
    ```
