
??? tip "📊 top"
    ### 📊 top

    top — инструмент реального времени для мониторинга системы и процессов.

    Показывает общее состояние системы:

    - uptime → время работы системы
    - users → активные пользователи
    - load average → средняя нагрузка

    CPU:

    - user → пользовательские процессы
    - system → ядро
    - idle → простой CPU
    - iowait → ожидание диска

    Memory и Swap:

    - total → всего памяти
    - used → используется
    - free → свободно
    - cache → кэш
    - swap → резервная память

    Процессы:

    - PID → идентификатор процесса
    - USER → владелец процесса
    - %CPU / %MEM → нагрузка
    - COMMAND → команда запуска

    ```bash
    top -o %CPU
    top -o %MEM
    top -u root
    ```


??? tip "📊 htop"
    ### 📊 htop

    htop — интерактивная версия top с удобным интерфейсом.

    Отличается тем, что:

    - дерево процессов
    - цветовая нагрузка CPU/RAM
    - удобное управление

    ```bash
    htop
    ```


??? tip "📊 ps"
    ### 📊 ps

    ps — снимок процессов в момент выполнения команды.

    В отличие от top:

    - не обновляется
    - показывает статическое состояние

    Основные режимы:

    ```bash
    ps
    ps aux
    ```

    ps aux включает:

    - все процессы системы
    - пользователей
    - CPU / RAM
    - команды запуска

    Используется когда нужно:

    - найти процесс
    - проверить состояние сервиса

    ```bash
    ps aux | grep nginx
    ```


??? tip "🧨 kill"
    ### 🧨 kill

    kill отправляет сигналы процессам.

    Основные сигналы:

    - SIGTERM (15) → корректное завершение
    - SIGKILL (9) → принудительное завершение
    - SIGSTOP → остановка процесса
    - SIGCONT → продолжение работы
    - SIGHUP → перезапуск процесса

    Используется когда нужно:

    - завершить процесс
    - принудительно остановить зависший процесс

    ```bash
    kill PID
    kill -9 PID
    ```


??? tip "🆔 pidof"
    ### 🆔 pidof

    pidof — получение PID процесса по имени.

    Используется когда нужно:

    - найти процесс
    - передать PID в kill

    ```bash
    pidof nginx
    ```


??? tip "⚙️ systemctl"
    ### ⚙️ systemctl

    systemctl — управление сервисами systemd.

    Управление сервисом:

    - start → запуск
    - stop → остановка
    - restart → перезапуск
    - reload → перечитать конфигурацию

    Проверка состояния:

    - status → подробная информация
    - is-active → активен ли сервис

    Автозапуск:

    - enable → включить автозапуск
    - disable → отключить автозапуск

    Список сервисов:

    - list-unit-files → все сервисы системы

    Состояния:

    - active / inactive / failed
    - enabled / disabled

    ```bash
    systemctl status nginx
    systemctl restart nginx
    systemctl enable nginx
    ```
